# Markdown rules

- Frontmatter fields that exist must be filled: `zone`, `legal_owner`,
  `portability`, `sensitivity`. Unknown is a valid value; blank is not.
- Label every material claim: decided, reported, inferred, proposed, unknown.
- Every factual line in a compiled section cites an evidence ID that exists.
  Check that it exists by reading the log rather than trusting the citation.
- Compiled sections are the only rewritable regions. Everything else appends.
- No em dashes. Commas, colons and parentheses instead.
- Do not restate POLICY.md. Link to it.
